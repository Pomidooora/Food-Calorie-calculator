# 食光 · 食物热量计算器

中文网页工具，预置常见食材，支持克重、品牌热量范围、自定义食材、分餐、熟后每100克热量与用油摄入比例。清单保存在浏览器本地，不需要账号或 API 密钥。

## 运行

需要 Python 3；在本仓库执行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

然后使用浏览器打开服务。页面无构建步骤，无第三方运行依赖，也不依赖外部字体或网络服务。

## 验证

需要 Node.js 18 或更新版本：

```sh
node --test tests/nutrition.test.mjs
```

## 估算方式

每项热量 = 可食部重量（克）× 每100克热量 ÷ 100。分别累加上下限，再除以份数或熟后总重。熟后总重影响热量密度，不改变整份热量；烹饪方式仅记录，不应用未经验证的热量折扣。油摄入比例仅作用于预置的油和香油。默认所有食材、油与酱汁全部吃下。

预置数据是用于日常估算的常见范围，并非某个品牌的检测结果或统计置信区间。肉类默认生重，米饭按熟重，乌冬面按湿面，干面与麦片按干重；自定义食材按所填数据对应状态称重。包装食品请优先按实际营养标签覆盖数据（千焦 ÷ 4.184 = 千卡）。区间无法覆盖所有产品差异，也无法自动推算弃汤或沥油造成的热量损失。
